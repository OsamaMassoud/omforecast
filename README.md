# 🌤️ OmForecast — Modern Weather Application

A clean, highly responsive, and real-time weather forecasting web application built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. Designed with a **Mobile-First** approach, it provides seamless cross-device compatibility, instant geolocation fetching, and advanced caching powered by **TanStack Query (React Query)** and the OpenWeatherMap API.

🔗 **Live Demo:** [https://osamamassoud.github.io/omforecast/](https://osamamassoud.github.io/omforecast/)

---

## ✨ Key Features

- **📱 Fully Mobile-Responsive:** Pixel-perfect layout designed for smartphones, tablets, and desktop displays.
- **📍 Geolocation Support:** One-tap feature to fetch local weather based on the user's current GPS location.
- **⚡ Real-Time Weather Metrics:** Displays detailed temperature, humidity, wind speed, pressure, and multi-day forecasts.
- **🔍 Global City Search:** Easily search, inspect, and track weather conditions for any city worldwide.
- **🚀 Optimized Caching & Performance:** Powered by TanStack Query for minimal network requests, smart polling, and smooth UX.
- **🌙 Dark / Light Mode:** Built-in theme context with system preference detection and local storage persistence.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, Shadcn UI
- **State & Data Fetching:** TanStack Query (React Query v5)
- **Routing:** React Router DOM v6 (configured with Base Path for Subdirectory Deployment)
- **Icons:** Lucide React
- **Deployment:** GitHub Pages

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- An active API key from [OpenWeatherMap](https://openweathermap.org/api)

### Installation & Setup

1. **Clone the repository:**
    git clone [https://github.com/OsamaMassoud/omforecast.git](https://github.com/OsamaMassoud/omforecast.git)
    cd omforecast

2. **Install dependencies:**
    npm install

3. **Configure Environment Variables:**
    Create a `.env` file in the root directory and add your API key:
    VITE_OPENWEATHER_API_KEY=your_openweather_api_key_here

4. **Run the application:**
    npm run dev
